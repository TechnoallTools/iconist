# آیکونیست (Iconist)

افزونه‌ی سبک و رایگان وردپرس برای تبدیل خودکار آیکون‌های SVG جهت استفاده و ویرایش رنگ در المنتور.

## معرفی

آیکونیست یک افزونه‌ی مکمل المنتور است. وقتی نصب می‌شود، هر فایل SVG که در رسانه‌ی وردپرس آپلود شود را به‌صورت خودکار بررسی کرده و مقادیر `fill` و `stroke` را به `currentColor` تبدیل می‌کند تا رنگ آیکون از داخل ویجت‌های المنتور به‌راحتی قابل تغییر باشد.

## امکانات

- **تبدیل خودکار هنگام آپلود** — بدون هیچ کار اضافه‌ای، هر SVG آپلودی بلافاصله برای استفاده در المنتور آماده می‌شود.
- **تبدیل دسته‌جمعی** — تبدیل تمام آیکون‌های قبلی موجود در رسانه با یک کلیک، همراه با نوار پیشرفت.
- **لیست استثناها** — امکان استثنا کردن فایل‌هایی مثل لوگوی برند که رنگشان نباید تغییر کند.
- **نسخه پشتیبان خودکار** — پیش از هر تبدیل، یک نسخه پشتیبان از فایل اصلی ذخیره می‌شود.
- **بررسی وضعیت سرور** — نمایش وضعیت ابزارهای موردنیاز هاست برای عملکرد صحیح افزونه.

## نصب

1. فایل zip افزونه را از بخش [Releases](../../releases) دانلود کنید.
2. در پیشخوان وردپرس به مسیر **افزونه‌ها > افزودن افزونه** بروید.
3. گزینه‌ی **بارگذاری افزونه** را انتخاب و فایل zip دانلودشده را بارگذاری کنید.
4. افزونه را نصب و فعال کنید.

## استفاده

پس از فعال‌سازی، از مسیر **تنظیمات > آیکونیست** وارد پنل تنظیمات شوید. از این پنل می‌توانید تبدیل خودکار و نسخه پشتیبان‌گیری را روشن/خاموش کنید، تبدیل دسته‌جمعی آیکون‌های قدیمی را اجرا کنید، فایل‌های استثنا را مدیریت کنید و وضعیت سرور را بررسی نمایید.

## نیازمندی‌ها

- وردپرس ۵.۰ یا بالاتر
- PHP نسخه ۷.۴ یا بالاتر
